Quick Keyboard & Board Guide

Navigation

  • Panning: Drag with hand tool, or hold Space + Drag mouse.
  • Zooming: Pinch trackpad, scroll mouse wheel, or use + and - keys.
  • Reset View: Click the zoom percentage.

Tools Shortcuts

  • V - Select / Pointer
  • S - Sticky Note
  • R - Rectangle Shape
  • C - Circle Shape
  • T - Textbox
  • D - Brush Drawing
  • E - Eraser Tool
  • A - Arrow Connection

Core Editing Tools

  • Copy/Paste: Use standard Ctrl+C / Ctrl+V (or Cmd keys) to clone items.
  • Undo/Redo: Use Ctrl+Z and Ctrl+Y to travel through edit history.
  • Micro-Nudging: Move elements with directional Arrow keys. Hold Shift to jump in larger grids.
  • Eraser: Click and hold with the eraser tool over paths or shapes to clean up items instantly.
